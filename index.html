Pipeline & Hosting

Auto-updates (runs on its own):

  • Daily 10:00 AM ET — full board: scores, bet settlements (W/L), injuries, player props, games, best bets, combos
  • Player props are rebuilt each run (PTS, REB, AST, 3PM, STL, BLK, PRA/PR/PA/RA) with residual learning + DraftKings lines
  • Finished games stay off main tabs and post to Bankroll as W/L

Host (static, free options):

  • GitHub Pages — push the HTML + JSON
  • Netlify / Vercel — drag-and-drop the folder
  • Cloudflare Pages

This file is fully self-contained. After each automation run, re-open or refresh the file for the latest props.
